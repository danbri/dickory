## Structural representation

`Datasets.lean` reuses ordinary RDF graphs, with one unnamed default graph and a partial function from IRI-or-blank graph names to graphs. A name selects at most one graph. Different names may select equal graphs, including a graph equal to the default. A converse construction takes any possibly infinite set of pairs with a name-uniqueness proof and recovers exactly those pairs as a lookup. Thus the functional representation neither loses nor adds permitted associations. No finiteness or disjoint-blank requirement is introduced. One blank domain is shared by graph-name keys and every component graph.

The representation distinguishes `some emptyGraph` from `none`. The proofs establish that a dataset containing one empty named graph differs from the empty dataset, although their named-quad projections agree. A blank used only as an empty graph's name still counts as an occurring blank. The stronger result in `DatasetExamples.lean` shows that the two structures are not even dataset-isomorphic.

The converse representation criterion is also proved: equal default graphs, equal graph-name presence and equal named-quad membership imply exact dataset equality. An eventual storage refinement must preserve all three. Quad membership is a locally defined projection used to expose information loss, not a separately stated W3C semantic condition. Concepts' informative advice about applications tolerating untracked empty graphs does not make those abstract datasets equal.

## One global isomorphism

`DatasetIsomorphism.lean` follows Concepts §4.1: one global blank renaming and its inverse, fixing IRIs and literals, extend pointwise to triples and graphs. They preserve the default graph and every named pair in both directions. The maps are total on the common ambient blank type; inverse laws are required only on occurring blanks. That occurrence set includes blank graph-name keys, even when their graphs are empty.

The source's named-pair biconditional is proved with an explicit source-domain condition on the name and graph. Both-direction preservation also prevents additional target pairs from escaping the definition. Identity, inverse and composition are constructed. The same maps induce the existing graph-isomorphism structure on default and corresponding named graphs, so component logical equivalence follows from earlier proofs rather than a separate semantic argument.

## Equivalent replacement can break sharing

`DatasetExamples.lean` gives a finite witness to Semantics §10's caution:

```text
                   dataset false       dataset true
default graph      i i _:false          i i _:true
named graph i      _:false i i          _:false i i
```

The default graphs are graph-isomorphic by exchanging the two blank identities and are therefore simply logically equivalent. Every named graph remains unchanged. A global dataset isomorphism would have to map `false` to `true` to preserve the default graph and to `false` to preserve the named graph. Lean proves that no such isomorphism exists.

One abstract IRI and two abstract blank identities suffice; no concrete literal syntax or datatype theory is needed for this structural counterexample. The formalized reading of “structurally similar” is the separately defined dataset-isomorphism relation. This is not a dataset non-entailment theorem.
